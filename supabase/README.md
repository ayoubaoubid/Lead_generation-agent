# Supabase

Cette frontière accueillera la configuration locale, les migrations versionnées, les
tests RLS et les données de développement minimales. Aucune migration ni instance
distante n’est créée ou modifiée pendant l’initialisation du dépôt.

Avant toute évolution, vérifier la version courante du CLI et de la documentation,
puis tester séparément les droits Data API, les policies RLS et l’isolation entre
agences et clients.
